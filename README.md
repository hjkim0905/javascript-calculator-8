# javascript-calculator-precourse

## 과제1 - <➕문자열 덧셈 계산기➕> 기능 구현 목록

### 입력 처리

- [x] "덧셈할 문자열을 입력해 주세요." 메시지 출력
- [x] 사용자로부터 문자열 입력받기 (`Console.readLineAsync()` 사용)
- [x] 빈 문자열 입력 처리 (0 반환)

### 구분자 처리

- [x] 기본 구분자(쉼표, 콜롬)로 문자열 분리
- [x] 커스텀 구분자 파싱 (`//`와 `\n` 사이의 문자 => 구분자)
  - [x] `//`와 `\n` 제거 (''로 replace)
  - [x] `.filter(Boolean)` 사용하여 '' 제거
- [x] 커스텀 구분자로 문자열 분리
- [x] 커스텀 구분자와 기본 구분자가 공존한다면 동시 처리하여 문자열 분리

### 숫자 추출 및 계산

- [x] 구분자를 기준으로 문자열 분리
- [x] 분리된 문자열을 숫자로 변환
- [x] 숫자들의 합 계산
  - [x] 더해지는 값들이 숫자인지 재확인(`!isNaN` 사용)

### 예외 처리

- [x] 숫자가 아닌 값 입력 시 `[ERROR]` 메시지와 함께 Error 발생
- [x] 음수 입력 시 Error 처리
- [x] 잘못된 커스텀 구분자 형식 처리 (커스텀 구분자를 만드는 // \n 이 없는데 기본 구분자 말고 다른 숫자가 아닌 문자열이 있을때)
  - [x] 기본 구분자(쉼표, 콜론), 커스텀 구분자가 아닌 기호가 있을 때 (e.g. 1:2?3)
  - [x] `//`와 `\n`사이에 커스텀 구분자가 존재하지만 둘 중 하나가 잘못 입력되었을 때 (e.g. 1:2//?\3?4 또는 1:2/?\n3?4)
- [x] Error 발생 시 `process.exit()`을 호출하지 않고 Error throw

### 출력

- [x] 계산 결과 출력 (`Console.print()` 사용)
- [x] 결과 형식: `결과 : {숫자}`
